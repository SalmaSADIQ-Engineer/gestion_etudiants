# Gestion des étudiants

## Description

Application Python permettant de calculer la moyenne et le résultat des étudiants.

## Technologies utilisées

- Python 3
- Pytest
- Git
- GitHub

## Installation

### Cloner le dépôt

```bash
git clone URL_DU_DEPOT
```

### Accéder au projet

```bash
cd gestion_etudiants
```

### Créer un environnement virtuel

```bash
python -m venv venv
```

### Installer les dépendances

```bash
pip install -r requirements.txt
```

## Exécution

Pour exécuter l'application :

```bash
python src/main.py
```

## Tests

Pour lancer les tests automatisés :

```bash
python -m pytest -v
```
